---
check: Samstämmighet svenska och engelska
---

## Purpose
<!-- sv 0f417a10 -->

Syllabi with both a Swedish and an English version should have **the same number of learning outcomes and the same structure** in both languages. When a translation leaves out outcomes or adds more, the two risk differing in substance, which is a formal problem for international students. The outcomes should also be presented as a **bulleted list** in both languages; running text makes the outcomes harder to tell apart and to review.

## Method
<!-- sv b974af91 -->

Two checks are run on each syllabus that has both a Swedish and an English version:

1. **The same number of outcomes.** The number of outcomes in the `Lärandemål` section is compared with the number in `Learning Outcomes`. They should be identical; any difference of 1 or more is flagged. The count is based on bulleted lists (`-`/`*`) first. Where there is no bulleted list, paragraphs that are not introductory phrases (lines ending in `:`) are counted instead, so that running text is not wrongly reported as *0 outcomes*.
2. **Bulleted form.** Outcome sections that have content but no bulleted list are flagged separately for each language (`Not a bulleted list (Swedish)` / `Not a bulleted list (English)`), even when the numbers agree.

**Limitations:**

- Only number and structure are compared. The **quality** of the translation (terminology, style, accuracy) cannot be measured automatically.
- If one language merges bullets (*"a, b, samt c"* in one bullet) while the other keeps them apart, it is flagged although the substance is the same.
- Syllabi with no English version at all are left out (legitimately: not every course is given in English). If only the `### Learning Outcomes` heading is missing within the English version, English counts as 0 outcomes and the difference is flagged.

The list is meant as a basis for discussion. A final judgement needs a reviewer who reads both versions side by side.

## Data source
<!-- sv bf738f9f -->

- Course syllabi at Dalarna University, from du.se, that have **both** a Swedish and an English version of the learning outcomes.
- Threshold: a difference of 1 or more between the languages (every discrepancy is flagged).

## Recommendations
<!-- sv da87fd46 -->

1. **Review each flagged syllabus** with both language versions side by side.
2. **Bring the bullets into line** at the next revision if the content really is the same.
3. **If the substance differs:** choose the version that should apply and update the other. Record which version led.
