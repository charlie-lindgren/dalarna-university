## Purpose
<!-- sv 106bde0e -->

The *Programmets kurser* section of a programme syllabus (the programme's courses) lists the courses in the programme. When du.se marks a course as discontinued, the course leaves Dalarna University's active catalogue, but the text of the programme syllabus is not updated with it, so references remain to courses that are no longer offered. The aim of the analysis is to find **which programme syllabi still list discontinued courses**, so that the text can be revised before students rely on an out-of-date list of courses.

## Method
<!-- sv 056a666d -->

The course list of each programme syllabus (the *Programmets kurser* section) is gone through course by course. Each course, whether it is given as a link or as plain text, is looked up in the list of courses that du.se has marked as discontinued. A match means that the course can no longer be taken but is still listed in the programme.

## Data source
<!-- sv 50591eab -->

- All programme syllabi at Dalarna University.
- The list of discontinued courses on du.se.

## Recommendations
<!-- sv 2596cb86 -->

1. **Change the reference to the replacing course.** When a discontinued course has a current successor (the same main field of study and the same size), update the programme's course list to the new code or name.
2. **Remove the course from the programme.** When there is no replacement and the course is no longer essential to the qualification's outcomes, remove the reference and adjust the programme's total credits if needed.
3. **Take it to the programme director.** The course list of a programme syllabus is the programme director's decision. The QA report shows where changes are needed, but not which way is right.
